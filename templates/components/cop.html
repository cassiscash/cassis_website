Scheme. Marks this as a COP order endpoint for the wallet to dial.
Endpoint ID. The server's Iroh endpoint ID: its 64-character hex Ed25519 public key. This key is the merchant's whole address, with no domain or certificate, and Iroh authenticates the connection against it.
Relay (optional). A custom Iroh relay to reach the server through instead of the default relays, such as the merchant's own or a .onion Tor hidden service. Only the wallet's transport uses it. It is never sent to the server.
Parameters (optional). &-separated key=value pairs handed to the server in hello, such as a table or till number.
