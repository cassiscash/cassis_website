Documentation

Everything you need to understand, implement and ship the Cassis interlayer payment protocol.

Cassis routes bitcoin payments across layers — Lightning, Liquid, Arkade, Cashu, Fedimint, Rootstock — using chains of hash time-locked contracts instead of trusted bridges or wrapped tokens.

Start with how it works for the mental model, then follow the quickstart to build your first route, or jump to for wallet developers to integrate Cassis and the Cassis Order Protocol (COP) into a wallet. Path finding covers how routers announce themselves and how payers choose which ones to trust. Also see offline payments and privacy.
